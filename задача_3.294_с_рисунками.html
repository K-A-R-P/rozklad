№ 3.294
Моторная лодка на реке и озере
📋 Условие
Моторная лодка плыла 2 ч по реке и 5 ч по озеру. Найдите, сколько всего километров прошла моторная лодка, если по озеру она двигалась со скоростью 21 км/ч, а по реке — на 4 км/ч быстрее.
📌 Дано:
Время движения по озеру: t₁ = 5 ч
Скорость по озеру: v₁ = 21 км/ч
Время движения по реке: t₂ = 2 ч
Скорость по реке: v₂ = v₁ + 4 = 21 + 4 км/ч
Sобщ — ?
💡 Объяснение: Лодка плыла в двух местах — по озеру и по реке. По озеру она плыла медленнее (21 км/ч), а по реке — быстрее (25 км/ч), потому что течение помогает. Нужно найти, какое общее расстояние прошла лодка.
🎨 Наглядный рисунок
📏 Общий путь лодки (отрезковая диаграмма)
общ = 105 + 50 = 155 км Общий путь = путь по озеру + путь по реке
💡 Видишь? Путь разделили на два отрезка: синий — по озеру, оранжевый — по реке. А общая длина — сумма обоих!
🚀 Скорости на линейке
💡 По реке быстрее — течение помогает! Скорость увеличивается на 4 км/ч: 21 + 4 = 25 км/ч.
📊 Таблица-схема пути
общ = 105 + 50 = 155 км
🗺️ Как лодка плыла (схема маршрута)
💡 Сначала лодка плыла по озеру — тихо, спокойно, 5 часов. Потом вошла в реку — течение помогло и стало быстрее!
✏️ Решение
  1. 1
    Найдём скорость лодки по реке:
    v₂ = 21 + 4 = 25 (км/ч)
  2. 2
    Найдём расстояние, пройденное по озеру:
    S₁ = 21 · 5 = 105 (км)
  3. 3
    Найдём расстояние, пройденное по реке:
    S₂ = 25 · 2 = 50 (км)
  4. 4
    Найдём общее расстояние:
    Sобщ = 105 + 50 = 155 (км)
✅
Ответ: 155 км
